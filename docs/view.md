# Source preview

```sh
grafic view examples/gl/ring.gfrag
grafic view examples/waves/waves.gvert
grafic view examples/tex/clouds.gtex
grafic view examples/mesh/radial.gmesh
```

Open a `.gfrag` fragment shader, `.gvert` vertex shader, `.gtex` texture, or
`.gmesh` mesh directly. Fragment shaders and
textures fill the window, with UVs from zero to one. For shaders, `time` advances
in seconds and `resolution` follows the framebuffer size, including display
scaling. Resize the window to change the aspect ratio.

Save the file to reload it. Source contents are checked every 200 ms, including
atomic saves and files removed and recreated by an editor. Unchanged contents
are not recompiled. A failed edit leaves the last working preview running;
the title shows an error state and the terminal gives the diagnostic. Fixing
and saving the source restores the preview. An initially invalid source or
required texture leaves an empty window until corrected.

Space pauses or resumes animation. Reloading preserves playback time and pause
state. Escape or the window close button exits. Minimized windows keep watching
the sources while rendering is suspended.

## Procedural textures

Bind `.gtex` sources directly to the shader's texture slots:

```sh
grafic view examples/compositions/masked-reveal/masked-reveal.gfrag \
  --tex0 examples/compositions/masked-reveal/mask.gtex \
  --tex1 examples/compositions/masked-reveal/rings.gtex
```

`--tex0` through `--tex3` generate and bind textures without intermediate PNG
files. Paths are relative to the working directory. Each source is watched
independently: editing a texture regenerates only that slot, and editing the
shader leaves textures intact. Failed edits keep the last working shader and
textures. Errors remain visible until the affected input is fixed.

Press `1` to see the shader, or `2`–`5` to inspect supplied `tex0`–`tex3` inputs.
The window title names the selected output. Unbound slots are skipped. Switching
preserves the shader, playback time, and pause state; inputs continue reloading
while you inspect a texture, even if the shader currently has an error.

Textures default to 512 × 512 pixels and noise seed 42. Set
`--texture-width N`, `--texture-height N`, and `--seed N` to override these for
all supplied textures. Window resizing affects shader `resolution`, without
regenerating textures. Texture generation runs when a source changes; textures
do not animate with shader time.

The viewer uses the same RGBA byte conversion as PNG export, with UV origin at
the bottom left. Sampling uses linear filtering and clamps at the edges; use
`repeat()` or `mirror(texN)` for wrapping. A shader using an unbound texture slot
reports which `--texN` option is needed.

## Meshes

Mesh sources generate geometry directly, without intermediate OBJ files. The
viewer keeps full XYZ positions and uses an angled orthographic camera with
depth testing. Framing comes from the source geometry and preserves proportions
when the window resizes. Vertex animation does not change the framing.

UV colors are the default: U is red and V is green. Press `W` to toggle
wireframe and inspect triangles; `U` toggles UV colors over a supplied fragment
shader. Press `1` to return from a texture input to the surface, or `2`–`5` to
inspect supplied textures. Reloading preserves the selected mode.

Try `examples/mesh/disk.gmesh`, `examples/mesh/radial.gmesh`, and
`examples/waves/waves.gmesh` to compare geometry and UV mappings.

## Vertex shaders and composed surfaces

Opening `.gvert` previews the shader on the same grid generated by `grid()`:
size 2 by 2, with 64 subdivisions along X and Z, and Y up.

```sh
grafic view examples/waves/waves.gvert
grafic view examples/waves/waves.gmesh \
  --vert examples/waves/waves.gvert --frag examples/waves/waves.gfrag \
  --tex0 examples/waves/ripples.gtex
```

Use `--frag FILE.gfrag` to supply a surface color program. The default vertex
shader preserves positions; the default fragment shader displays UV colors.
Fragments receive interpolated displaced local-space `surface.position`,
`surface.uv`, and `surface.normal`. Vertex programs return
`vertex(position, uv)` with optional authored normals as the third argument.
`screen.position` and `screen.uv` describe the framebuffer independently. The paired `waves.gfrag` example blends
blue, turquoise, and pale crests using `surface.position.y()`, with directional lighting
from authored, interpolated wave normals, shader-generated sky reflections,
Fresnel strength, and sun glints. `view.direction` points toward the viewer in
surface-local space. Two scrolling samples of `ripples.gtex`, supplied with `--tex0`, perturb the
shading normal without changing geometry. Press `2` to inspect the map and `1`
to return to the water. A subtle screen-space fade blends toward a chosen color. The vertex, fragment, and mesh sources live
together in `examples/waves/`; edit them to explore motion, color, and geometry.
A `.gfrag` source still opens fullscreen unless `--mesh` or `--vert` requests a
3D surface. Each role can be supplied once; a primary file already fills its
own role. Use `--tex0` through `--tex3` for fragment texture inputs.

Mesh, vertex, fragment, and texture sources reload independently. A bad shader
edit retains its previous program, and a bad mesh edit retains its previous
geometry. Fixing another input still updates that input. The last `.show()` in
each source selects its intermediate output; `--preview-line` applies only to
the primary source. Vertex inspection accepts a vertex value or a `vec3` position; position-only
inspection preserves complete-program attributes when available.

## Intermediate outputs with `.show()`

Place `.show()` at the point you want to preview:

```text
uv
.multiply(4.5)
.noise()
.show()
.smoothstep(0.4, 0.68)
.colorize(rgb(1.0, 1.0, 1.0))
```

In the viewer, the last `.show()` in each file, in source order, selects that
file's output. Later stages are excluded from evaluation. The entire file must
still parse. A marker in a texture changes the image supplied to the shader;
the viewer stays on your selected output. Switch to the texture to inspect that
same intermediate image directly.

Fragment and texture markers accept scalar and vector values. Scalars display as opaque grayscale;
`vec2` fills red/green with blue zero and alpha one; `vec3` gets alpha one;
`vec4` preserves all channels. Without a marker, the full program must return
`vec4`. Mesh markers must return `mesh`:

```text
disk()
.segments(8)
.show()
.rings(24)
```

This previews the mesh before the final subdivision change. Names for markers
are not supported yet.

Normal `grafic gl`, `grafic tex`, and `grafic mesh` compilation treats `.show()` as an identity
operation and compiles the complete program. Explicit `--preview-line N`
overrides markers for the file opened directly; bound textures still use their
own markers.

## Window and preview options

```sh
grafic view --width 1280 --height 720 examples/gl/ring.gfrag
grafic view --preview-line 4 examples/gl/ring.gfrag
grafic view --preview-line 3 examples/tex/clouds.gtex
```

`--width` and `--height` set the initial window size (default 960 × 640).
`--preview-line N` displays the last expression point on a one-based source
line, using the same conversions as the compiler's `--preview-line N`. A selected
line without an expression reports a preview error.

## Building

The default package includes the viewer. It requires GLFW 3 and OpenGL headers
and libraries in addition to the compiler dependencies. The renderer uses an
OpenGL 3.3 core context through GLFW. No display is needed to build Grafic or run
the compiler and asset tests.

```sh
make                     # All compilers and viewer
make CAPABILITIES=gl      # Shader compiler only, without windowing dependencies
```

The `view` capability requires `gl`, `tex`, and `mesh`. Linux builds discover GLFW and
OpenGL through `pkg-config`; macOS builds use GLFW and the system OpenGL framework.
